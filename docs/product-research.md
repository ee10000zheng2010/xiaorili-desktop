# 小日历产品调研与功能决策

## 参考对象

- TickTick：任务清单、重复任务、提醒、日历视图、跨设备同步。
- Rainlendar：桌面常驻、透明/皮肤、轻量离线日历和事件显示。
- Microsoft To Do：任务分组、重复提醒、我的一天、跨设备数据保持。
- Linear：高密度信息层级、键盘优先、低干扰导航。
- Notion：温和表面、内容优先、低噪声边框。
- Raycast：命令入口、快捷键、快速搜索和桌面效率工具。

## 已落地

- 桌面小组件和开机显示开关。
- 月、周、日、年视图。
- 提醒中心和重复提醒字段。
- 待办搜索、状态筛选、Ctrl/Cmd+K 快速聚焦。
- 本地数据保留、导入导出和主题/背景偏好保留。
- GitHub Releases 自动更新通道。

## 后续优先级

1. 云端同步：以用户账号或同步文件夹作为跨电脑数据源，解决多设备冲突。
2. 日历导入：支持 ICS 文件和系统日历订阅。
3. 更细提醒：提前 5/15/30 分钟、系统通知、逾期提醒。
4. 任务组织：项目/清单、优先级、拖拽排序和子任务。
5. 桌面交互：快捷添加、托盘菜单、透明度和窗口位置记忆。

## 取舍

小日历优先保持轻量、离线可用和桌面可见，不直接复制复杂协作软件。云端同步需要账号、服务端和冲突解决策略，列为下一阶段；当前用本地数据加导入导出保证升级不丢数据。
